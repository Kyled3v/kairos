# Versioning Policy

KAIROS uses Semantic Versioning:

MAJOR.MINOR.PATCH

## MAJOR

Breaking architecture, API or compatibility changes.

## MINOR

Backward-compatible functionality or capabilities.

## PATCH

Backward-compatible bug fixes, security fixes and maintenance.

## Pre-1.0

Versions below 1.0.0 represent active development.

## Intelligence Versioning

KAIROS separately tracks:

- software version
- architecture version
- model version
- knowledge/index version
- evaluation version

This allows an intelligence result to be reproduced against the exact system configuration that produced it.
