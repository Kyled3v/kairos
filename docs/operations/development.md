# Development Operations

## Standard Development Cycle

1. Inspect repository state
2. Read applicable architecture
3. Define objective
4. Implement smallest coherent change
5. Test
6. Validate
7. Update documentation
8. Update KAIROS_STATE.md
9. Update CHANGELOG.md
10. Assess version impact
11. Commit
12. Push

## Repository Integrity

The working tree must be clean before beginning a release.

## AI Development

AI coding agents must follow AGENT_INSTRUCTIONS.md.

AI-generated code is treated exactly like human-written code and must pass the same validation.
