# Architecture Decision Records

Architecture Decision Records document significant technical decisions.

## Naming

ADR files use:

ADR-NNN-short-description.md

Example:

ADR-001-model-abstraction.md

## Required Sections

- Status
- Date
- Context
- Decision
- Alternatives
- Consequences
- Security considerations
- Ownership/licensing considerations

## Rule

Architectural decisions must be documented before they become difficult to reverse.
