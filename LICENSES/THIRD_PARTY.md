# Third-Party Dependency Registry

This registry records third-party software, models, datasets and services used by KAIROS.

KAIROS must not imply ownership of third-party components.

Every dependency must be evaluated before production use.

## Registry

Currently no third-party runtime dependencies have been approved.

## Required Record

Every dependency must document:

- Name
- Version
- Category
- Source
- License
- Commercial-use status
- Modification rights
- Distribution requirements
- Data/privacy implications
- Security status
- Replacement strategy
- Approval status
