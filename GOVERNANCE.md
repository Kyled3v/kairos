# Governance

KAIROS is a KyleDev Software Systems project.

## Governance Priorities

1. User safety and control
2. Security
3. Technical integrity
4. Capability
5. Maintainability
6. Transparency

## Authority

Repository governance is defined by:

- KAIROS Constitution
- Security Policy
- Architecture Decision Records
- Versioning policy
- Repository state

## Change Control

No AI coding agent may override repository governance.

Human maintainers retain final authority over production architecture and releases.
